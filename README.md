# 📝 To-Do List

A simple and clean To-Do List web application built using HTML, CSS, and JavaScript.

This project helps users add and manage their daily tasks in an easy and simple interface.

---

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- ✏️ Edit tasks
- 💾 Save tasks using Local Storage
- 📱 Responsive design
- 🎨 Clean and simple user interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- DOM Manipulation
